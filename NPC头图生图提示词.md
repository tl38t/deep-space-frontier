# 深空星疆 · NPC 头图生图提示词

> **用途**：复制下方任意一段完整 prompt，粘贴到 Gemini（或任意生图工具）即可出图。
> **尺寸**：1024 × 1536（3:4）；建议质量 high。
> **落盘命名**：`nsk_npc_<原型id>_<变体序号1-4>.webp`（原型 id 见各节标题括号内）。
> **来源**：由 `game/js/data/asset-prompts.js` 的 `buildNpcPrompt(archId, variant)` 真实拼装，与后台美术页一致。
> **发色规则（逐原型手挑）**：第 3 段「变体」已写入发色，且同一原型下 4 个变体发色互不重复（蜜桃粉 / 香槟金 / 铂金白 / 薰衣草紫 / 薄荷银 / 铜红 …）。
> **卖肉向（清凉版）**：若要让女角色（V1）穿清凉 / 显身材，另见 `清凉版NPC头图生图提示词.md`（同原型 V1 叠加逐原型专属清凉穿搭）。
> **义眼 / 义肢版本**：见 `义眼义肢NPC头图生图提示词.md`。
